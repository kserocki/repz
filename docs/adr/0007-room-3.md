# ADR-0007: Room 3

- **Status:** Accepted (2026-10-28)

## Context
Krzysztof wants the newest Kotlin-first stack. Room 3.0.x is stable.

## Decision
Use `androidx.room3` 3.0.3 with KSP per target and the bundled SQLite driver.

## Consequences
Fewer examples online, so verify APIs against official docs. KSP wiring with the AGP 9 KMP library plugin is verified in the first spike.
